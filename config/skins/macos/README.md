# macOS Skin Assets

Place the following files here:

- `monterey.jpg` — macOS Monterey wallpaper (or any macOS wallpaper you prefer)

## Where to get wallpapers

macOS wallpapers are copyrighted by Apple but widely available:
- [512pixels macOS wallpaper collection](https://512pixels.net/projects/default-mac-wallpapers-in-5k/)
- Use any 5K landscape photo as alternative

## Theme dependencies (installed automatically)

- **WhiteSur-gtk-theme** — GTK theme mimicking macOS Monterey
- **WhiteSur-icon-theme** — macOS-style icons
- **Plank** — macOS-style dock
